## The headline: the language selector graph is CLOSED

After removing (a) selectors the corpus defines, (b) engine builtins
(`builtins.txt` — control flow, object protocol, arithmetic, the lowercase
Cocoa leakers), and (c) interior-capital ObjC selectors:

- **language porting candidates: 1** — `action:` (1 send, `Cocoa action:` at
  50_cocoapad.mst:48; genuinely undefined but rides the ObjC noSuchMethod
  bridge, verified working in sprint 13b). i.e. **zero** genuine
  sent-but-undefined pure-Smalltalk selectors.
- cocoa-bridge candidates: 153 — the ObjC surface (`initWithFrame:`,
  `setTarget:`, `addSubview:`, …), dispatched through objc_msgSend. Not a
  language gap; a bridge-coverage concern.

**Verdict:** porting is NOT about missing language features. Every selector the
corpus sends, something already answers (a corpus method, the prelude, an
engine helper, or the Cocoa bridge). The work is **dynamic correctness of
DEFINED selectors** (the primitive audit) and the **platform/FFI tier**.

## How to read the artifacts

- `methods.tsv` — every method: file, class, side, selector, argc, primitive
  kind, line. The authoritative static map (join target for the ledger).
- `classes.tsv` — file, class, super, #ivars, #methods.
- `sends.tsv` — selector, static send count, defined_by_corpus. What the
  corpus references, priced.
- `candidates_lang.tsv` / `candidates_cocoa.tsv` — the partitioned
  sent-but-undefined lists (the ranked porting shortlist vs the ObjC surface).

## Caveats (honest limits of a static pass)

- "Defined" = a selector is defined by SOME class or the prelude (dynamic
  dispatch means any class could be the receiver) — it does not prove the
  right class answers a given send.
- Cocoa classification is the interior-capital heuristic plus `builtins.txt`;
  a few lowercase ObjC getters (alloc/frame/…) are listed there by hand.
- This pass says nothing about whether a defined selector is CORRECT — that is
  the dynamic battery's job (primitive_coverage, A/B, protocol probes). The two
  are complementary: static closes "is it referenced?", dynamic closes "is the
  answer right?".
